# Садака — Цифровая платформа пожертвований для мечетей Таджикистана

## 🎯 Краткое описание

Мобильная платформа для прозрачного сбора и управления пожертвованиями в мечетях Таджикистана. Платформа обеспечивает доверие через систему одобрения кампаний **Комитетом улемов Таджикистана** и обязательную отчётность мечетей.

**Ключевое отличие**: Система **Савоб** (духовная награда), которая мотивирует пользователей к регулярным пожертвованиям.

---

## 📋 Основные сущности

### Роли системы
1. **Комитет улемов** — государственный регулятор
   - Одобряет/отклоняет кампании мечетей
   - Полная статистика по стране
   - Может блокировать мечети

2. **Мечеть** — оператор
   - Создаёт кампании сбора
   - Обязана публиковать отчёты об использовании средств
   - Управляет QR-кодами

3. **Жертвователь** — пользователь приложения
   - Выбирает мечеть или кампанию
   - Жертвует онлайн
   - Получает Савоб и видит отчёты

---

## 🕌 Функциональность

### Профиль мечети
- Название, адрес, фото
- Имам и контакты
- История кампаний и отчётов
- QR-код для пожертвования
- Рейтинг и прозрачность

### Кампании
- Создание: название, описание, целевая сумма, срок
- Статусы: **Черновик → На одобрении → Активна → Завершена**
- Прогресс-бар в реальном времени
- Уведомления жертвователям

### Обязательная отчётность
- После кампании мечеть публикует отчёт
- Отчёт: расходы, фото подтверждения, сумма
- **Без отчёта новая кампания не запускается**
- Механизм доверия платформы

### Система Савоб
- Баллы за каждое пожертвование (не имеют денежной ценности)
- История добрых дел в профиле пользователя
- Множители в праздники (Рамадан x2, x3)
- Мотивирует к регулярным пожертвованиям

### Карта мечетей
- Интерактивная карта всех мечетей
- Фильтрация: по городу, активным кампаниям, рейтингу
- Ближайшая мечеть по геолокации

---

## 💳 Платёжные системы

- Карты: Visa, Mastercard, Коrti Milli
- Мобильные кошельки: Alif, IMON
- QR-код на мечети (офлайн → онлайн)
- Перспектива: SMS-пожертвование

---

## 🔐 Механизмы доверия

| Механизм | Описание |
|----------|----------|
| Верификация мечетей | Только одобренные Комитетом мечети |
| Обязательная отчётность | Нет отчёта = нет новой кампании |
| Прозрачность транзакций | Каждый видит общую сумму сборов |
| Государственный надзор | Комитет улемов имеет полный доступ |
| Блокировка нарушителей | Мечети за нарушения блокируются |
